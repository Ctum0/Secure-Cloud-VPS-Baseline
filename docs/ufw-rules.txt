# UFW Firewall Rules

Exact output of `sudo ufw status verbose` on the hardened VPS.

## Status

```
Status: active
Logging: on (low)
Default: deny (incoming), allow (outgoing), deny (routed)
New profiles: skip
```

## Rule Table

| To                         | Action   | From      |
|----------------------------|----------|-----------|
| 22/tcp (OpenSSH)           | ALLOW IN | Anywhere  |
| 60000:61000/udp            | ALLOW IN | Anywhere  |
| 80/tcp                     | ALLOW IN | Anywhere  |
| 443/tcp                    | ALLOW IN | Anywhere  |
| 2822/tcp                   | ALLOW IN | Anywhere  |
| 22/tcp (OpenSSH (v6))      | ALLOW IN | Anywhere (v6) |
| 60000:61000/udp (v6)       | ALLOW IN | Anywhere (v6) |
| 80/tcp (v6)                | ALLOW IN | Anywhere (v6) |
| 443/tcp (v6)               | ALLOW IN | Anywhere (v6) |
| 2822/tcp (v6)              | ALLOW IN | Anywhere (v6) |

## Rules in Command Form

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 60000:61000/udp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 2822/tcp
sudo ufw enable
```

## Notes

- Default incoming policy is `deny`; only the ports above are reachable.
- `60000:61000/udp` and `2822/tcp` are exposed for service-specific needs —
  review them before running in production and close anything unused.
